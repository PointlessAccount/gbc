  - Then positional base-60 system similar to modern base-10.

## Week 2 - Bits and Bytes
- Bit is a binary digit represents two states, 0 or 1.
  - Byte is a Group of 8 bits
- Ram is Volatile Memory and Hard Drives or Solid State drives are non volatile - aka storage = non volatile and ram = lose work / data if loss of power.
- Punch cards were used with early computers from the 50s to up until the early 80s
- Morse Code relied on power/telephone lines
